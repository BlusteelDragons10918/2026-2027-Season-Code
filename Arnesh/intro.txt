Add branch to vscode: 
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/BlusteelDragons10918/2026-2027-Season-Code.git
git push -u origin main


To switch: 
git fetch origin
git checkout member-code

Create your own personal folder:
mkdir name

create a file touch your-name/file 

to make a folder inside the folder: 
mkdir -p your-name/folder-name
